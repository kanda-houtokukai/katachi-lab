## 1. 確定した決定（ユーザー決定）

- **[DECISION] D1 対象と公開範囲**：小学1〜3年生とその保護者を対象にする。家庭での利用を想定し、一般公開する。療育現場向けの特化はしない。
  - 理由：対象を家庭に絞ると、内容・難易度・画面の判断がぶれない。
- **[DECISION] D2 課金**：当面は無料で公開し、有料級の品質づくりを先にする。課金は後から足せる構造にしておく。
  - 理由：有料級かどうかの評価は、使われて初めて得られる。通信費がかからず維持費はほぼゼロなので、無料でも続けられる。
- **[DECISION] D3 AIの使い方**：AIは制作時だけ使う。アプリはAIのAPIを呼ばず、通信なしで動く。
  - 理由：常時AIを動かす構成は取らない（ユーザー方針）。これにより、子ども向けAIの規約対応・安全対策・通信費の負担がなくなる。
- **[DECISION] D4 内容の範囲**：学習指導要領（文部科学省）に沿った内容を芯にし、応用を効かせて多機能にする。
  - 理由：ユーザー方針。家庭で使う教材として、学校の学習とずれないようにするため。
- **[DECISION] D5 独立案件**：漢字アプリ（じぶん字典）・プログラミングランドとは別の案件として扱う。構成も世界観も引き継がず、ゼロから作る。
  - 理由：ユーザー方針。
- **[DECISION] D6 品質の条件**：①多機能 ②高アニメーション ③充実した内容 ④応用 ⑤有料級 の5つを満たすこと。2章の提案は、この5条件を満たす前提で Claude に委ねられている（2026-10-08）。
  - 理由：ユーザー方針。文章だけの提案では判断できないため、判断は触れる見本で行う。
- **[DECISION] D7 アニメーションの水準**：見本「はこの形と展開図」v1 の水準で合格（2026-10-08）。以後の単元もこの水準をそろえる。
  - 理由：ユーザーが見本を見て判断。
- **[DECISION] D9 網羅の意味**：機能だけでなく、内容の種類と数もすべて網羅する（2026-10-08）。立体なら、学習指導要領で扱う立体を小1〜中1まですべて入れ、展開図は種類と数をすべて扱う（`docs/rittai-design.md`）。
  - 理由：ユーザー方針（「種類も数も網羅に含まれる」）。
- **[DECISION] D10 リポジトリと公開**：GitHub の kanda-houtokukai アカウントに公開リポジトリ `katachi-lab` を作り、GitHub Pages で公開する。正式公開までは検索に出ない設定（noindex と robots.txt）にする（2026-10-08）。
  - 理由：ユーザー決定。実機（iPad）で URL を開くだけで確かめられる。リポジトリ名は仮の名前で、アプリ名は別に決める。
- **[DECISION] D11 夜間の自走**：2026-10-08 の夜、Claude Code が設計済みの範囲を止まらずに実装する。判断が要る場面は、指示書の既定の選択で進め、台帳の「朝の確認事項」に記録する（2026-10-08）。
  - 理由：ユーザー方針（「途中で止まることは不要」）。
- **[DECISION] D12 デザインは仮で進める**：今夜の実装は見本v2の見た目を仮のデザインとして使う。色・字体・余白は1か所（デザイン用の変数）にまとめ、方向性が決まったら差し替えるだけで全画面が変わるようにする（2026-10-08）。
  - 理由：デザインの方向性はユーザーが実機で決める事項（3章）。自走を止めずに、後から差し替えられる形にしておく。
- **[DECISION] D17 読み上げの声**：読み上げは端末の音声のまま使う。Gemini TTS は使わない。Google Cloud Text-to-Speech の Gemini TTS も使わない（2026-10-09）。
  - 理由：ユーザー決定。Gemini API の追加規約と、Google Cloud 個別サービス規約の第20条d（生成AIサービスを、18歳未満が使う・使う可能性が高いアプリの一部として使わない）に当たるため。Google Cloud Text-to-Speech の Gemini TTS も、一般提供の生成AI機能として同じ条項の対象になる。
- **[DECISION] D8 有料級の基準**：主な有料サービスの機能を網羅したうえで、独自であること（2026-10-08）。判定は competitors.md の網羅表で行う。
  - 理由：ユーザーの求める水準。見本v1の時点では網羅も独自性も足りていなかった（competitors.md 1章）。見本v2で、1単元の見本で示せる範囲の×は解消した。

## 2. 提案（D6の5条件を満たす前提で委任済み。見本で確かめながら固める）

### P0 見本「はこの形と展開図」（2026-10-08 v1）

アニメーションの水準と「多機能・応用」の具体像を確かめるための、1単元ぶんの見本。Artifact として公開済み（タイトル「はこの形と展開図」）。

- みる：箱が落ちてきて回り、ひらいて面に番号がつき、また閉じる
- さわる：スライダーで開閉、指で回す、「めん・へん・ちょうてん」を順に数える（箱が回って数える面をこちらへ向ける）、面をタッチすると向かい合う面が分かる（4年の先取り）
- ためす：「はこに なるかな？」6問。答えたあと実際に組み立てて確かめ、重なる面は赤く残る
- つくる：マットのマスに6枚ならべて組み立てる。箱になれば「ずかん」に登録、「かみで つくる」でのりしろ付きの展開図（A4・1マス4.5cm）を表示・PDF保存
- ずかん：全11種の開き方を集める
- 計算部分は機械検証済み：6枚の並べ方35種を総当たりし、箱になるのがちょうど11種であること、のりしろ7か所が重ならずに付くことを確認

この見本で確定ではないもの：見た目（色・字体・世界観）、ボタンの大きさ、キャラクターの有無。いずれも3章のとおり後で決める。

### P0-2 見本 v2（2026-10-08）：網羅表の不足分を同じ見本に組み込んだ

同じ URL を更新。v1 の機能はすべて残している。

- さわる：「さいころ／おかしの はこ（直方体）」を切りかえ。直方体の辺は同じ長さごとに色分けし、4本ずつあることを示す。向かい合う面をタッチすると「同じ形・同じ大きさ」と示す
- ためす：難しさ3段（やさしい・ふつう・チャレンジ）。チャレンジに「★と向かい合う面をタッチ」を追加。ヒント3段（そこにする面を示す→途中まで折る→ほぼ折る）。ヒントを使って正解した問題は星を薄く表示
- つくる：3つに分けた
  - うつしとる（2年）：箱の面をタッチすると紙にスタンプのように写る。同じ形の面を2枚ずつ重ねて確かめ、6枚をつないで箱に戻す
  - ほねぐみ（2年）：長さの違うひご3種とねんど玉で骨組みを作る。長さを間違えるとはじかれる
  - てんかいず（4年）：v1 の機能＋ヒント3段（まだ見つけていない開き方をうすく示す）
- きょうのミッション：思い出し問題・ためす・日がわりの活動の3つ。思い出し問題は正解すると1・3・7・14・30日後に再出題、間違えると翌日。がんばった日は累計で数える
- 読み上げ：画面の文章を端末の音声で読む。スピーカーボタンで聞き直せる（収録音声は制作工程で用意する）
- おうちのひとへ：家のアイコンを2秒長押しで開く。取り組んだ日・時間・ずかん・思い出し問題の正答率、つまずきの見立て（5型。記録から規則で選ぶ）とおうちでできること、ほめどころ、学校の学習との対応表、最近の記録
- 設定：利用時間の目安（こえると30秒の休けい）、読み上げの自動／手動、ためすの初めの難しさ、きょうだい登録（4人まで）、記録のファイル保存・読み込み、見本の記録で表示、記録を消す（確認つき）
- 記録はきょうだいごとに端末内へ保存。外部へは送らない

### P1 拡張前提の骨格（5層）

| 層 | 中身 | 拡張のしかた |
|---|---|---|
| 操作部品 | 立体を折る・開く／10のまとまり／時計の針／水とはかり／図形の頂点を引っぱる 等 | 一度作れば、別の単元・別の学年で使い回せる |
| 単元データ | 部品の組み合わせ・手順・問題・ヒントをデータで書く | 新しい単元はデータを足すだけで増やせる |
| 学びの型 | 全単元を同じ段の並びにそろえる（P2） | 単元をまたいでも子どもが迷わない |
| 学習記録 | 何を・いつ・どこで・どう間違えたかを、全単元同じ形で残す | 保護者画面とつまずき判定の材料になる。後からそろえると過去分の作り直しになる |
| 地図 | 指導要領の項目と、単元どうしの前提関係（例：10のまとまり→くり上がり→ひっ算） | 世界観（マップの絵柄）は見た目の皮として別に持ち、中身と切り離す |

### P2 学びの型と「応用」の置き場所

- 1単元を **みる→さわる→ためす→つくる** の4段にそろえる。
- 応用（D4）は2か所に置く。
  - 「つくる」の段：学んだことを使って自分で作る・確かめる
  - 「ちょっと先」の道：上の学年の内容へ続く先取りの道（例：2年「はこの形」→4年「展開図」）

### P3 制作時のAIで作り込むもの（D3の具体化）

- 単元データの下書き（手順・問題・ヒント）
- 誤答パターン表：単元ごとのよくある間違いと、それに合わせて見せ直す動き
- 保護者向け文面：つまずきの型ごとの説明と、家でできる声かけ。アプリは記録から型を判定して該当の文面を出す
- ナレーション・効果音（音声合成で収録）、絵（画像生成）
- **収録前の確認**：教科書と学習指導要領を拠り所にして確かめる。一次資料なしで作ったデータは、何度も直すことになる。

### P4 最初の2単元

骨格が拡張に耐えるかを試すため、性格の違う2単元を同時に作る。

- **はこの形→展開図**（2年→4年の「ちょっと先」）：紙ではもっとも想像しにくい題材。立体を折る・開く部品を作る
- **時計**（1〜2年）：長針を回すと短針もじわじわ動く。回転と連動という別系統の部品になる

次の候補：くり上がり（10のまとまり）、かけ算の並び（3×4を回すと4×3）、太陽と影（3年理科）、電気の通り道（3年理科）。

### P5 技術方針

- ブラウザで動くアプリ（PWA）にする。インストールでき、オフラインで動く
- データは端末内に保存する。機種変更に備えて、記録の書き出し・読み込み（バックアップ）を持つ
- 立体は Three.js（ブラウザで3Dを描く定番の部品）で描く
- 公開は無料のホスティング（GitHub Pages ＋ fknd.jp のサブドメイン）
- 対応端末：iPad、家庭のスマホ、持ち帰りのGIGA端末（Chromebook等）

### P6 機能の柱（「多機能」の中身。網羅表の不足分を反映 2026-10-08）

1. **単元**：4段＋「ちょっと先」。全単元に次の3つを標準で持たせる
   - 音声の読み上げ（制作時に音声合成で収録。1年生でも一人で進められる）
   - 段階的なヒント（答えは言わず、1段ずつ近づける）
   - 難しさのレベル（やさしい・ふつう・チャレンジ）
2. **きょうのミッション**：その日に取り組む短い一回分（10〜15分）を提示する。忘れかけた頃の復習を混ぜる（2年で学んだ立体を4年まで思い出させる役もここ）
3. **実験室**：単元で使った部品を自由にいじれる場所。単元を終えるごとに使える部品が増える
4. **紙で作る**：自分で開いた展開図などを、のりしろ付きの実寸で印刷し、切って組み立てて確かめる
5. **図鑑・作品集**：集めた形や、作った展開図が並ぶ
6. **ごほうびと世界観**：単元を進めると世界が育つ。連続日数でなく累計日数で数える
7. **保護者画面**：学習レポート（何を・いつ・どこで手が止まったか）、つまずきの型の説明と家での声かけ、ほめどころ、指導要領の項目との対応。通知の代わりに、同じ端末の「おうちのひとへ」画面で見る
8. **きょうだい登録**：1台の端末で子どもごとに記録を分ける
9. **設定**：学年、先取りの可否、音・動きの量、利用時間の目安（休憩の合図つき）
10. **記録の書き出し・読み込み**（P5）

「はこの形」単元に足す中身（2年の教科書の活動。教科書で確認してから作る）：
- 直方体（お菓子の箱のように面の大きさが違う箱）。向かい合う面が同じ形になることを確かめる
- 箱の面を紙に写し取り、写した6枚を組み合わせて箱にする
- ひごとねんど玉で箱の骨組みを作る（辺12本・頂点8つ）

### P7 差別化の軸（根拠は competitors.md 4章）

- 低学年の立体を、動かして学ぶ（有料の総合サービスにない空白地帯）
- 2年で学んだ立体を、4年まで忘れさせない（間をあけた思い出し→4年の展開図へ渡す）
- 答えを教えずに、動かして確かめさせる（全単元の共通原則）
- 紙と手に戻す（のりしろ付きの実寸印刷）
- 保護者には、つまずきの型を文章で返す（P3・P6-7）
- ネットなし・登録なし・広告なしで動く

独自ではないもの（無料教材に既存）：6枚を並べて組み立てる、11種集め、展開図の開閉アニメ、向かい合う面の表示。これらは見せ方の質で上回るが、差別化の根拠にはしない。

### P8 一般的な配慮

音・動きの量を調整できるようにする。端末の「視差効果を減らす」設定にも従う（療育向けの特化ではなく、一般的な設定として）。

## 3. ユーザーが決めること（後日・実機で）

- 見本v2の中身が D8 の基準を満たすか（実機で触って判断）
- キャラクター（案内役）を入れるか。入れる場合、絵と動きは別工程で用意する（コードで描くと記号的な水準が上限のため）
- 世界観・デザインの方向性（P1b で、触れる比較案から選ぶ）
- 保護者向け文面・思い出し問題の下書き（`reviewed:false`）を、教科書と照らして確認する（正式公開の前）
- ボタン・文字の大きさ、操作の手触り（実機で指で触って決め、「実機で決めた値」として固定する）
- アプリの名前（リポジトリ名 katachi-lab は仮）
- 正式公開の時期（それまでは検索に出ない設定）

## 4. やらないこと

- 問題数やドリルの量で勝負すること
- アプリの実行中にAIのAPIを呼ぶこと（D3）
- 単元ごとに専用の作りを増やすこと（部品とデータで作る）
- 最初から全教科に広げること
- 連続ログイン日数で追い立てること（休むと記録が消える仕組みにしない）
- 押しても何も起きないボタンを残すこと（試作でも実際に動かす）
- 説明テキストを画面に書き込みすぎること（必要な瞬間だけ出す）

## 5. 調査で確かめた事実（根拠・2026-10-08）

- 展開図は4年「直方体と立方体」の内容。低学年で立体を扱うのは、1年「かたちあそび」と2年「はこの形」（面6・辺12・頂点8、向かい合う面は同じ形）まで。教科書会社によって時期が異なる場合があるため、単元を作るときに教科書で確かめる
  - https://eleschool-compass.com/contents/sansu/tangen/g2-hako.php
- 展開図の3D学習アプリは既にある。ただし中学受験向けの有料アプリ（ワンダーファイ「究極の立体＜展開＞」4,500円）
  - https://app-liv.jp/5336422/
- 小学生向け学習アプリの人気ランキング上位10本は、すべて無料のドリル・知育型
  - https://my-best.com/15603
- 有料サービスとの比較の詳細は competitors.md。要点は次のとおり
  - 低学年で立体を指で動かして学べる有料サービスは見つからなかった（スマイルゼミは4〜5年のみ）
  - RISUの学習データでは、小1〜3でつまずきの多い単元の2位が立体図形。2年で出て4年まで出ないため忘れやすいと説明している
  - 6枚を並べて組み立てて確かめる機能と11種集めは、2026年公開の無料Web教材（まなまる、でじらぼ）がすでに持っている
  - のりしろ付きで印刷できる教材と、2年から4年をつなぐ教材は見つからなかった
  - https://hugkum.sho.jp/484871 ／ https://www.manamaru.net/tenkaizu ／ https://deji-lab.com/three/
