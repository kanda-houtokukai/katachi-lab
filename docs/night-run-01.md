## 3. 技術方針（既定の選択）

- **ビルドなしで動く ES モジュール**。GitHub Pages にそのまま置ける形にする。Node はカタログ生成とテストにだけ使う。
- **Three.js は r128 を同梱**（`vendor/three.module.js`。npm の `three@0.128.0` の `build/three.module.js` をコピー）。見本v2と同じ版で、見え方をそのまま移せる。更新は別の作業で行う（今夜はしない）。
- **jsPDF 2.5.1 を同梱**（`vendor/jspdf.umd.min.js`）。ネットなしで PDF 保存できる。
- **デザイン用の変数は `app/ui/tokens.css` の1か所**（D12）。色・字体・角丸・影・余白をここに集め、各画面は変数だけを使う。字体は見本と同じ Klee One と Zen Maru Gothic。Google Fonts から読み込み、オフライン時は端末の丸ゴシックに落ちる。
- **ディレクトリ**
```
index.html            地図（ホーム）と単元画面を出す1枚のページ
app/core/             保存（try/catch必須）、記録、ミッション、思い出し、保護者画面、設定、読み上げ、効果音、文字
app/engine/           立体の定義、展開（全域木）、合同判定キー、折りたたみ、重なり判定、のりしろ、印刷
app/stage/            3Dの土台（マット、光、影、カメラの枠どり、紙ふぶき）
app/parts/            操作部品（下の一覧）
app/units/            単元データ（JSON）。r1.json r2.json r4.json r5a.json r5b.json r6.json rj.json
app/ui/               tokens.css、共通の部品（ボタン、棚、字幕、シート）
data/nets/            生成した展開図カタログ（solidId.json）
tools/build-catalog.mjs
tests/unit/           node --test
tests/e2e/            Playwright
vendor/               three.module.js、jspdf.umd.min.js
docs/ reference/ CLAUDE.md HANDOFF.md
```
- **操作部品（`app/parts/`）**：1つの部品を複数の単元で使い回す。単元データは部品の組み合わせと文言・問題・ヒントだけを持つ。
  - `fold-explore`（開閉・回転・数える・向かい合う面・重なる辺と頂点・平行と垂直）
  - `net-quiz`（なる／ならない、★の問題、カードの問題）
  - `net-build-grid`（方眼に並べる。立方体）
  - `net-build-cards`（面のカードを辺につなぐ。直方体・角柱・角錐・正多面体）
  - `stamp`（面を写し取る）、`skeleton`（ひごとねんど玉）
  - `sketch`（見取図の点線）、`position`（位置の表し方）
  - `slope-roll`、`stack`、`sort`（1年）
  - `prism-grow`（n角柱が育つ）、`cylinder-roll`（円柱を転がして側面を残す）
  - `volume-fill`（1cm³で埋める・水を注ぐ）、`volume-slice`（底面を積み重ねる）
  - `platonic-vertex`、`revolve`、`projection`、`pour`（中1）
  - `random-net`（正十二面体・正二十面体）
  - `zukan`、`paper`（のりしろ付き印刷）
- **単元を足す方法**：`app/units/` に JSON を1つ足し、地図の定義に1行足す。部品の新設が要らないことを N7 の確認項目にする。

## 5. 落とし穴（見本v1・v2で実際に踏んだもの）

- **カメラの回転アニメが残って、新しい枠どりを上書きする**。回転は「回転の世代番号」を持ち、枠どりのたびに番号を進めて古い回転を無効にする（見本v2 `spinCamera`）。
- **縦長の画面で、物が画面の外に出る**。縦長では展開図を縦向きに回してから置く（`fitCells`）。紙と箱の配置も縦長用に切り替える。カメラの距離の上限は 34。
- **カメラの追従をフレーム数に依存させない**。経過時間で追従させる（遅い端末で枠どりが遅れる）。
- **棚（下の操作欄）の高さが変わったら、いまの見え方のまま枠に収め直す**（ResizeObserver）。
- **休けいの合図が保護者画面の上に出る**。保護者画面を開いている間は時間を数えない。目安を変えたら「いまから1分後」以降に合図する。
- **画面が非表示のとき requestAnimationFrame は止まる**。終了の判定を毎フレームの監視に置かない。
- **iOS は入力欄の文字が16px未満だと勝手に拡大する**。入力欄は16px以上。
- **タッチ端末に hover の解除は来ない**。長押しボタンは `-webkit-touch-callout:none`。
- **読み上げの声の一覧は後から届く**（`onvoiceschanged`）。日本語の声がない端末では読み上げボタンを隠す。
- **localStorage は例外を投げることがある**。読み書きはすべて try/catch。
- **ヘッドレスのブラウザは描画が遅い**。テストで固定の秒数を待たず、カメラが目標に近づいたこと・アニメが終わったことを条件で待つ。
- **★を付けた面を折りたたむと、★が箱の内側に隠れる**。開閉に合わせて印の位置を面の表と裏で入れ替える。
- **タップで答える問題でヒントが形を折ったままにすると、答える面が隠れる**。見せたあと平らに戻す。
