# 有料級サービスとの網羅表（低学年向け学習アプリ・仮称未定）

正本：このファイル（2026-10-08 作成・同日 見本v2 を反映）。決定事項リスト（decisions.md）の D6・D8 の判定に使う。

---

## 1. 結論

- **見本v2（2026-10-08）で、有料の標準のうち1単元の見本で示せるものは×がなくなった。** 残る×は「教科・単元の幅」と「手書き入力」だけで、どちらも単元を増やす工程（P3・P4）で埋める。保護者への通知は、通信なしの方針（D3）により同じ端末の画面で置き換えている
- **見本v1の時点では、網羅も独自性も足りていなかった。** 展開図の操作まわりは有料サービスより作り込めている。一方で、有料サービスなら当然ある機能（保護者レポート、読み上げ、ヒント、レベル、復習の自動提示、きょうだい登録など）がまだ入っていない
- **見本の「つくる」と「ずかん」は独自ではない。** 2026年に公開された無料のWeb教材2本（まなまる「立方体の展開図づくり」、でじらぼ「立体探偵の挑戦状」）が、6枚を並べて組み立てて確かめる機能と、11種集めをすでに持っている
- **独自にできる余地ははっきりある。** 低学年で立体を動かして学べる有料サービスは見つからなかった。RISUの学習データでは、小1〜3でつまずきの多い単元の2位が立体図形だった。2年で一度出たあと4年まで出てこないため忘れやすい、という説明も付いている。ここを埋める作りが、独自性の芯になる

## 4. 独自性の芯（根拠つき）

1. **低学年の立体を、動かして学ぶ。** 有料の総合サービスにはなく、無料教材は4年以上向けか、カリキュラムのない道具型だけだった
2. **2年で学んだ立体を、4年まで忘れさせない。** RISUの説明（2年で出て4年まで出ないので忘れやすい）がそのまま根拠になる。2年の単元のあと、間をあけて思い出す小さな問題を出し続け、4年の展開図へ渡す
3. **答えを教えずに、動かして確かめさせる。** 正解を表示するのでなく、組み立てる・回すといった操作で子ども自身が確かめる。これを全単元の共通原則にする（時計なら針を回して確かめる、など）
4. **紙と手に戻す。** 自分で作った展開図を、のりしろ付きの実寸で印刷して組み立てる
5. **保護者には、つまずきの型を文章で返す。** 実行中にAIを呼ばず、制作時に作った文面を規則で選ぶ（D3）
6. **ネットなし・登録なし・広告なしで動く**

- 端末の音声での読み上げは、端末とブラウザによって声と対応が異なる。iPad・iPhone の実機で確かめる（未検証）
