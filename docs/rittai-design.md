# 立体の領域 設計書（katachi-lab）

これが正本（2026-10-08 作成）。立体の単元を作るときは、この設計書と `docs/decisions.md` を読む。
展開図の種類と数は、`reference/net_counter.py` で総当たりして確かめた値で、`reference/net-counts.json` に凍結してある。

## 0. この設計書の範囲と原則

### 0-1. 範囲（すべて網羅する）

学習指導要領で「立体」を扱う内容を、小学1年から中学1年まですべて入れる。対象は小学1〜3年なので、4年以上は「ちょっと先」の道として置く。

| 単元ID | 学年・単元 | 位置づけ |
|---|---|---|
| R1 | 1年「かたちあそび」 | 本編 |
| R2 | 2年「はこの形」 | 本編（見本v2で作成済み。骨格へ移す） |
| R4 | 4年「直方体と立方体」 | ちょっと先 |
| R5a | 5年「角柱と円柱」 | ちょっと先 |
| R5b | 5年「直方体や立方体の体積」 | ちょっと先 |
| R6 | 6年「角柱と円柱の体積」「およその形と大きさ」 | ちょっと先 |
| RJ | 中1「空間図形」 | ちょっと先（中学） |

前提関係（地図の層）：R1 → R2 → R4 → R5a → RJ、R4 → R5b → R6 → RJ（体積）。

### 0-2. すべての単元に共通する原則

1. **答えを教えずに、動かして確かめさせる。** 正誤は、組み立てる・回す・注ぐなどの動きで子ども自身が確かめられる形で返す。
2. **学びの型をそろえる。** みる → さわる → ためす → つくる ＋ ずかん。単元によって「つくる」の中身は変わるが、タブの並びは同じ。
3. **全単元に標準装備**：読み上げ（端末の音声）、ヒント3段（答えは言わない）、難しさ3段（やさしい・ふつう・チャレンジ）、学習記録（共通形式）、思い出し問題（間隔をあけて再出題）、保護者向けの見立て文面。
4. **数は計算で決める。** 展開図の種類はカタログ（事前計算）から引く。手で数えた数を画面に書かない。
5. **画面の文字**：子ども向けの文はひらがな・カタカナの分かち書き。教科書で使う用語は漢字＋ルビ（例：<ruby>展開図<rt>てんかいず</rt></ruby>、<ruby>直方体<rt>ちょくほうたい</rt></ruby>）。保護者画面は漢字かな交じり。
6. **説明を書き込みすぎない。** 指示は字幕として必要な瞬間だけ出し、読み上げる。常時表示の説明文は置かない。

- 上の値は、どの切り開き方でも面が重ならないことも確かめてある（重なりは0件）。
- **数は寸法に依存する。** 偶然同じ長さの辺があると、合同な展開図が増えて数が減る。アプリで使う寸法は `net-counts.json` の寸法に固定し、変えるときは計算し直して凍結値を更新する。
- 正十二面体・正二十面体は種類が多すぎて、全部を並べる図鑑にはしない。「ひらくたびに ちがう展開図」として、全域木を一様に選ぶ（Wilson のアルゴリズム）で毎回1つ作る。見つけた種類は合同判定のキーで数え、「みつけた ○ / 43,380」と表示する。プラトンの立体の辺展開はどれも重ならないことが知られているので、重なり判定は不要（念のため判定は通す）。
- 円柱・円錐は「長方形（おうぎ形）と円2つ（1つ）」の標準形を示し、円をつなぐ位置を側面の辺に沿って動かせるようにする。動かしても組み立てられることを見せる。

## 2. 汎用の立体エンジン（全単元の土台）

見本v2のエンジンは立方体の方眼専用だった。これを任意の凸多面体に一般化する。

### 2-1. 立体の定義（データ）
- 生成関数：`box(a,b,c)`、`prism(n|base, h)`、`pyramid(n|base, h)`、`platonic(name)`、`cylinder(r,h)`、`cone(r,h)`。
- 出力：頂点、面（外向きに反時計回り）、面の種類（例：`base`／`side`、形の名前）、辺の隣接（どの2面が接するか）、二面角。

### 2-2. 展開図カタログ（ビルド時に作る）
- Node のスクリプト `tools/build-catalog.mjs` で、面の隣接グラフの全域木を総当たりし、平面に開き、重なりを判定し、合同（回転・裏返し）で同じものをまとめる。
- 合同判定のキー：各面の各辺を、両向き×裏返しありで x 軸に合わせた全配置のうち、面の頂点列（丸め3桁）を並べた最小のもの。`reference/net_counter.py` と同じ考え方。**このキーで数えた数が §1 の凍結値と一致することをテストで保証する。**
- 出力：`data/nets/<solidId>.json` に、展開図ごとの { 番号, 全域木（どの辺でつながるか）, 平面での面の位置, サムネイル用の輪郭, 合同判定キー }。番号は、見本の立方体11種の番号と同じ並びを優先し、それ以外は「根からの深さが浅い順→キーの辞書順」で付ける。
- 正十二面体・正二十面体はカタログを作らない（§1）。

### 2-3. 折りたたみ
- 開いた形の各蝶番（親面と子面の共有辺）に、折る角度＝ π − 二面角 を持たせる。
- 進み具合 p（0〜1）に対して、根から浅い順に少しずつ遅れて起き上がる（見本と同じ動き）。
- 子の面は部分木ごと蝶番で回る（見本の入れ子の仕組みを一般化）。

### 2-4. 子どもが作った展開図の判定
- 子どもが作った開き方の合同判定キーを、その立体のカタログから引く。見つかれば「はこに なった」＋番号。見つからなければ「ならない」。
- 「ならない」とき：その開き方を、各蝶番の既定の角度（面の種類の組ごとに決める。例：三角柱の側面どうし＝60°の二面角）で折り、重なる面を赤く残す（見本と同じ見せ方）。面の種類の組に既定の角度がない（例：三角柱で三角形どうしを直接つないだ）ときは、その辺を赤く光らせて「この 2まいは となりあわないよ」と出す。

### 2-5. 重なる辺・重なる頂点（4年の中心の活動）
- 折りたたんだときに同じ位置へ来る外周の辺を組にする（見本の `edgePairs` を一般化）。
- 同じ位置に集まる頂点をまとめる（立方体なら1つの角に3つ）。

### 2-6. のりしろと印刷
- 外周の辺の組ごとに、どちらか一方へ台形ののりしろを付ける。全組み合わせを試して、のりしろどうし・のりしろと面が重ならない配置を選ぶ（見本の方法を一般化。三角形・五角形でも同じ）。
- 円柱・円錐：側面の継ぎ目に1つ、円の周りにギザギザののりしろを付ける。
- A4に実寸で収まる最大の縮尺を、1単位＝4.5cm を上限に自動で決める。紙に収まらない形は、用紙の向きを変えてから縮める。縮めたときは「1マス ○cm」を正しく書く。
- 出力：①印刷画面（`window.print()`、印刷用CSSで A4・余白0・実寸）②PDF保存（jsPDF を同梱。ネットなしで動く）。

## 3. 単元ごとの設計

各単元に、①ねらい ②みる ③さわる ④ためす ⑤つくる ⑥ずかん ⑦思い出し問題 ⑧つまずきの型と保護者向け文面 ⑨学習記録の種類 を書く。文面はすべて下書き（`reviewed:false`）として収録し、保護者画面には出すが、正式公開前にユーザーが教科書と照らして確認する（台帳の「朝の確認事項」に載せる）。

### R1 1年「かたちあそび」

- **ねらい**：箱・つつ・ボール（球）の形の特徴に気づく。平らなところと丸いところ、転がる・積める・すべるの違い。形を写し取る。
- **使う立体**：箱（直方体・立方体）、つつ（円柱。ジュースの缶やトイレットペーパーの芯のような寸法）、ボール（球）。身の回りの物は、商品名や商標の分かる絵を使わず、形と色だけで作る。
- **みる**：坂の上に3つの形を置くと、ボールは転がる、つつは横向きなら転がり縦向きならすべる、箱はすべる。ゆっくり再生できる。
- **さわる**：
  - 置く向きを変えて坂に置く（つつの向きで結果が変わることを確かめる）。
  - 積み木のように積む。ボールの上には積めない（落ちる動き）、つつは平らな面を上にすれば積める。
  - 形をタッチすると、平らなところ（青）とまるいところ（黄）が光る。
- **ためす**：
  - 仲間分け：身の回りの物（10種以上。箱・つつ・ボールの仲間）を3つのかごに分ける。分けたあと、坂に転がして確かめる。
  - 「ころがるのは どれ？」「つめるのは どれ？」
- **つくる**：
  - かたちを うつす：形を紙に押し当てると面の形が残る（箱→四角、つつ→まる、ボール→点のような小さなまる）。写った形から元の形を当てる。
  - つみきの まち：箱・つつ・ボールを積んで、決められた形（タワー・橋など）を作る。崩れるかどうかを動きで見せる。
- **ずかん**：集めた身の回りの物の形（箱・つつ・ボールの仲間ごと）。
- **思い出し問題**：「ころがるのは どれ？」「たいらな ところが ある かたちは？」など8問以上。
- **つまずきの型（下書き）**：「つつはいつも転がると考えている（向きで変わることに気づいていない）」「ボールも積めると考えている」。家での声かけ：缶やボールを実際に坂で転がす遊び。
- **記録**：`r1.sort`（仲間分けの正誤と間違えた物）、`r1.roll`、`r1.stack`、`r1.stamp`。

### R2 2年「はこの形」（見本v2を骨格へ移す）

- 見本v2（`reference/mock-v2.html`）の機能をすべて移す：みる、さわる（さいころ／おかしの箱、面・辺・頂点を数える、向かい合う面）、ためす（3段・ヒント3段・★の問題）、つくる（うつしとる・ほねぐみ・てんかいず）、ずかん、ミッション、読み上げ、保護者画面、設定。
- 追加：
  - **ためす「この 6まいで はこが できる？」**：面の形のカード（長方形・正方形）6枚を見せ、箱になるかを答える。違う大きさが混じる・同じ形が2枚ずつそろわない問題を入れる。答えたあと、カードが組み上がって確かめる（なる／すき間があく）。
  - **つくる「はこを えらぶ」**：大きさの違う面のカード12枚から6枚を選んで箱を作る（同じ形が2枚ずつ）。
- 「てんかいず」は 4年の内容なので、R4 の「つくる」と同じ部品で動かす（立方体のみ）。
- **つまずきの型**：見本v2の5型をそのまま移す（`reviewed:false`）。

### R4 4年「直方体と立方体」

- **ねらい**：直方体・立方体の定義、展開図（立方体11種・直方体54種と29種）、組み立てたときに重なる辺と頂点、見取図、面と面・辺と辺の垂直と平行、位置の表し方（平面・空間）。
- **使う立体**：立方体、直方体（3辺がすべて違う）、正四角柱（正方形の面が2つ）。寸法は `net-counts.json`。
- **みる**：
  - 直方体と立方体の見分け：面が長方形だけ／長方形と正方形／正方形だけ。
  - 箱を辺にそって切り開くと展開図になる。同じ箱でも切り開く辺を変えると違う展開図になる（切る辺を赤く示しながら開く）。
- **さわる**：
  - 展開図の開閉（立方体11・直方体54・29から選ぶ）。
  - **重なる辺**：展開図の外周の辺をタッチすると、組み立てたときにくっつく相手の辺が同じ色で光る。続けてスライダーで折ると、2本が近づいてぴったり重なる。
  - **重なる頂点**：頂点をタッチすると、同じ角に集まる頂点（立方体なら3つ）が光る。
  - **垂直と平行**：組み立てた箱で面をタッチすると、平行な面（青）と垂直な面（黄）が光る。辺をタッチすると、平行な辺（3本）と垂直な辺（4本）が光る。
  - **見取図**：箱を回すと、見えない辺が点線になる様子を見せる。
- **ためす**（3段）：
  - 「はこに なるかな？」（立方体＋直方体。直方体は、大きさの合わない辺がつながった形も出す）
  - 「★と むかいあう めんは？」「★と かさなる へんは？」「★と あつまる ちょうてんは？」
  - 「へいこうな めんは どれ？」「すいちょくな へんは どれ？」
  - 見取図の完成：見えない辺をタッチして点線にする。
  - 位置の表し方：平面（横・縦）と空間（横・縦・高さ）。箱の部屋の中の玉の位置を答える／指定の位置に玉を置く。
- **つくる**：
  - てんかいず（立方体）：見本と同じ方眼で6マス。
  - てんかいず（直方体）：面のカード6枚（大きさ3種×2枚）をトレーから選び、すでに置いた面の辺へつなげる。辺の長さが合う向きにだけ吸い付き、合わない辺には付かない（はじかれる動き）。6枚つないだら「くみたてる」。カタログで判定し、新しければ図鑑に登録。
  - かみで つくる：のりしろ付きの実寸印刷（立方体・直方体とも）。
  - さいころを つくる：展開図に目（1〜6）を書き入れる。向かい合う目の和が7になるように置けたかを、組み立てて確かめる。
- **ずかん**：立方体 11、直方体 54、正四角柱 29。それぞれ「みつけた ○ / 総数」。未発見は「？」。見つけた展開図はタップで開閉を再生。
- **思い出し問題**：直方体と立方体の定義、面・辺・頂点の数、向かい合う面、重なる辺、平行と垂直、位置の表し方 など12問以上。
- **つまずきの型（下書き）**：①箱にならない形を「なる」と答えやすい ②箱になる見慣れない形を「ならない」と答えやすい ③向かい合う面の見つけ方 ④重なる辺・頂点を隣の辺と取り違える ⑤平行と垂直の取り違え ⑥見取図で見えない辺を実線で描く ⑦位置の表し方で横と縦の順を逆にする。それぞれに家でできることを付ける（例：菓子箱を切り開いて重なる辺に同じ色のシールを貼る）。
- **記録**：`r4.net-quiz`、`r4.opp`、`r4.edge-match`、`r4.vertex-match`、`r4.para-perp`、`r4.sketch`、`r4.position`、`r4.build`（立体・番号・新規か）、`r4.dice`。

### R5a 5年「角柱と円柱」

- **ねらい**：角柱・円柱の底面・側面・高さ。面・辺・頂点の数のきまり。展開図（角柱の各種・円柱）。見取図。
- **使う立体**：正三角柱、二等辺三角形の三角柱、直角三角形の三角柱、正四角柱、直方体、正五角柱、正六角柱、円柱。
- **みる**：
  - 底面の形を三角形→四角形→五角形→六角形と変えると、角柱が育つ（スライダーで n＝3〜8）。底面は2つ、側面は長方形。
  - n を大きくしていくと円柱に近づく（n＝8 のあと、なめらかな円柱へ変わる）。
- **さわる**：
  - n 角柱の面・辺・頂点の数を表に記録しながら数える（面 n＋2、辺 3n、頂点 2n。表は子どもが数えて埋め、式は見せない）。
  - 展開図の開閉（各角柱・円柱）。円柱は側面を巻き取る・広げる動き。
  - **円柱の側面と円周**：円柱を紙の上で1回転転がすと、側面の長方形が残る。長方形の横の長さが、底面の円のまわりの長さと同じになることを、円周を直線に伸ばす動きで重ねて見せる。
- **ためす**（3段）：
  - 「この 展開図で 三角柱が できる？」（9・23・42種から＋できない形）
  - 「この 円柱の 展開図に あう 長方形は どれ？」（横の長さが違う3枚）
  - 「○角柱の 頂点は いくつ？」（表のきまりに気づいたかを見る）
- **つくる**：
  - てんかいず（角柱）：底面2枚＋側面のカードをつなげる（R4 と同じ部品）。カタログで判定し図鑑に登録。
  - てんかいず（円柱）：円の大きさを選び、側面の長方形の横の長さをスライダーで合わせる。合えば巻き上がって円柱になる。
  - かみで つくる：実寸印刷（角柱・円柱）。
- **ずかん**：正三角柱 9、二等辺三角形の三角柱 23、直角三角形の三角柱 42、正四角柱 29（R4 と共有）、直方体 54（R4 と共有）、正五角柱 99、正六角柱 354。
- **思い出し問題**：底面と側面、n角柱の数のきまり、円柱の側面の横の長さ など10問以上。
- **つまずきの型（下書き）**：①底面と側面の取り違え（横に倒した角柱で底面を下の面と思う）②円柱の側面の横の長さを直径にする ③角柱の展開図で底面を同じ側に2つ付ける。
- **記録**：`r5a.count-table`、`r5a.net-quiz`、`r5a.cyl-match`、`r5a.build`。

### R5b 5年「直方体や立方体の体積」

- **ねらい**：1cm³の立方体がいくつ分か。縦×横×高さ。cm³・m³・L の関係。組み合わせた形の体積。
- **みる**：1cm³の積み木で箱を埋める（1段ずつ）。1段の数×段の数＝縦×横×高さになる。
- **さわる**：縦・横・高さのスライダーで箱を変えると、積み木の数が変わる。10cmの立方体に水を注ぐと 1L になり、1000cm³ と同じになる。1m³の立方体の中に 1cm³ を並べ始めて、とても多いことを見せる（100万個）。
- **ためす**：体積を答える（数字の入力は大きなボタンのテンキー。手書きは数字の単元で扱う）。L字の形を2つの箱に分ける／大きな箱から引く。
- **つくる**：決められた体積（例：24cm³）になる箱を、縦・横・高さを選んで作る。いくつ作れるかを図鑑に集める（24cm³ なら 1×1×24 … 2×3×4 など、すべての組を計算で出して網羅する）。
- **つまずきの型（下書き）**：①縦×横で止める（面積と混同）②単位の取り違え（cm² と cm³）③L と cm³ の換算。
- **記録**：`r5b.volume`、`r5b.unit`、`r5b.compose`、`r5b.make`。

### R6 6年「角柱と円柱の体積」「およその形と大きさ」

- **ねらい**：角柱・円柱の体積＝底面積×高さ。身の回りの物を、およその形とみて体積を見積もる。
- **みる**：底面を薄い板として、高さの分だけ積み重ねる（三角柱・円柱）。
- **さわる**：底面の形と高さを変えると体積が変わる。円柱は底面の円の面積（半径×半径×3.14）を板で示す。
- **ためす**：底面積と高さから体積を答える。身の回りの物（缶・箱・ケーキ・プール）をどの形とみるかを選び、およその体積を選ぶ。
- **つくる**：決められた体積の角柱・円柱を作る（底面と高さを選ぶ）。
- **つまずきの型（下書き）**：①底面と側面の取り違え ②円の面積で直径を使う。
- **記録**：`r6.volume`、`r6.estimate`、`r6.make`。

### RJ 中1「空間図形」（中学・ちょっと先）

- **ねらい**：角錐・円錐、正多面体、回転体、投影図、展開図、錐体と球の体積・表面積。
- **使う立体**：正三角錐・正四角錐・正五角錐・正六角錐、円錐、正多面体5種、球。
- **みる**：
  - 正多面体が5種類しかないこと：1つの頂点に正三角形を3・4・5枚、正方形を3枚、正五角形を3枚集めるとできる。正三角形6枚・正方形4枚・正六角形3枚では平らになり立体にならない（集める動き）。
  - 回転体：長方形・直角三角形・半円・離れた長方形を軸の周りに回すと、円柱・円錐・球・ドーナツの形になる（残像を残しながら回す）。
- **さわる**：
  - 正多面体の面・辺・頂点の表（数えて埋める）。
  - 展開図の開閉（角錐・円錐・正多面体）。
  - 円錐の展開図：母線の長さと底面の半径をスライダーで変えると、側面のおうぎ形の中心角が変わる（中心角＝360°×半径÷母線。式は保護者画面と「ちょっと先」の説明でだけ示す）。
  - 投影図：立面図と平面図を見せ、立体を回して確かめる。
- **ためす**：
  - 「この 展開図で ○○が できる？」（角錐・正多面体）
  - 投影図から立体を当てる（円柱・円錐・角柱・角錐・球）。
  - 錐体の体積：円錐3杯分の水で同じ底面・高さの円柱がいっぱいになる（注ぐ動き）。
  - 球の体積：球がちょうど入る円柱の2/3。
- **つくる**：
  - てんかいず（角錐・正四面体・正八面体）：面のカードをつなぐ（R4 と同じ部品）。
  - 正十二面体・正二十面体：「ひらく」を押すたびに違う展開図が生まれ、図鑑に「みつけた ○ / 43,380」を記録。
  - 円錐の展開図づくり：おうぎ形の中心角を合わせて組み立てる。
  - かみで つくる：実寸印刷（角錐・円錐・正多面体）。
- **ずかん**：正四面体 2、正三角錐 4、正四角錐 8、正五角錐 15、正六角錐 33、正八面体 11、正十二面体・正二十面体（見つけた数のみ）。
- **つまずきの型（下書き）**：①錐体の体積で 1/3 を忘れる ②円錐の展開図で、おうぎ形の弧の長さと底面の円周を結びつけていない ③投影図の取り違え。
- **記録**：`rj.platonic`、`rj.net-quiz`、`rj.cone`、`rj.projection`、`rj.volume`、`rj.random-net`。
